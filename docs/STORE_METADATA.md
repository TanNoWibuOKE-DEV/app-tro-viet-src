## 6. Lệnh Đóng gói & Nộp duyệt (Production Deployment Commands)

1. **Biên dịch bản cài Android APK xem trước:**
   ```bash
   npm run build:apk
   ```
2. **Biên dịch gói Android App Bundle (.aab) chính thức cho Google Play:**
   ```bash
   npm run build:aab
   ```
3. **Nộp tự động gói .aab lên Google Play Console (Internal Testing Track):**
   ```bash
   npm run submit:android
   ```
