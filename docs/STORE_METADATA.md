| Số điện thoại | Xác thực tài khoản (OTP) & Liên hệ | Bắt buộc | **Không** |

## 5. Cấu hình Phân phối Thử nghiệm Beta (TP. Đà Nẵng)

1. **Phiên bản Web PWA (Truy cập nhanh trên điện thoại):**
   - URL thử nghiệm cục bộ: `http://localhost:8082` (đã build qua `npx expo export -p web`).
   - Hỗ trợ đầy đủ responsive, Touch gestures, Light/Dark mode.
2. **Phiên bản Android Standalone (APK):**
   - Sử dụng lệnh build EAS: `npx eas build -p android --profile preview`.
