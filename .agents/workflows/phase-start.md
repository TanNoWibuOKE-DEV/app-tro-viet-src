# /phase-start

Người dùng sẽ nói số phase (ví dụ "Phase 1"). Nếu chưa nói, đọc `docs/STATUS.md` để biết phase tiếp theo.

1. Đọc `docs/STATUS.md` và **chỉ đúng mục của phase đó** trong `docs/SPEC.md` Phần B, cùng các mục Phần A mà phase đề cập.
2. Kiểm tra phase trước đã đạt tiêu chí "Hoàn thành khi". Nếu chưa, nói rõ và dừng.
3. Tạo Implementation Plan (tối đa 1 trang): mục tiêu, danh sách bảng / API / màn hình sẽ tạo hoặc sửa, cách kiểm thử, rủi ro, việc **cố ý không làm** trong phase này.
4. Tạo Task List theo thứ tự, mỗi task đủ nhỏ để làm và kiểm tra trong một lượt.
5. Liệt kê tối đa 5 câu hỏi còn mở ảnh hưởng thiết kế. Những gì có thể giả định thì ghi vào `docs/ASSUMPTIONS.md`.
6. **Dừng lại và chờ tôi duyệt.** Không viết code ở bước này.
